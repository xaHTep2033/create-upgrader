# Create Upgrader GUI 0.2.0

Исходный проект для Minecraft 1.21.1, NeoForge 21.1.233, Java 21.
НЕ КОМПИЛИРОВАЛСЯ И НЕ ПРОВЕРЯЛСЯ в игровом клиенте. Готового JAR нет. Возможны ошибки API/поведения, требующие исправления по build log. Это прототип, не production-релиз.

## Сборка
JDK 21 + Gradle 8.14.3, затем из корня: gradle build
Результат успешной сборки: build/libs/create-upgrader-0.2.0.jar.
Gradle Wrapper не включён. Нужен интернет для загрузки зависимостей.
Или загрузить содержимое проекта в GitHub-репозиторий: workflow Build JAR соберёт artifact create-upgrader-jar. GitHub workflow в этой среде тоже не запускался.

## Установка
Удалить прежнюю версию Create Upgrader и поставить новый JAR в mods на клиент И сервер. Не устанавливать две версии одновременно. Сделать резервную копию мира. Самостоятельно поставить совместимые версии Create и аддонов — прямых зависимостей на них у апгрейдера нет.

## Использование
/give @s create_upgrader:upgrader
ПКМ предметом открывает GUI. Иконка пока использует vanilla clock, текстуры модов не копируются. Сам предмет не расходуется, рецепта нет.

Положить исходник в левый слот, выбрать цель в каталоге, нажать АПГРЕЙД. Каталог 36 предметов на страницу. Поиск по локализованному названию и registry ID. Для фильтра мода ввести namespace:, например create:. На маленьком экране уменьшить масштаб интерфейса: фиксированный размер окна 300x344.

В каталоге видны зарегистрированные предметы, кроме некоторых эвристически скрытых технических вариантов. Он НЕ получает весь серверный прайс: запрещённый предмет может отображаться, но сервер отклоняет его выбор (цель останется прежней). Цены выбранного входа и выхода синхронизируются с сервером. Пустой вход показывает цену 0.

Шанс = 0.8 * цена одного входа / цена одного выхода. Выход должен стоить строго дороже входа. Попытка сжигает один предмет из слота. Сервер сразу определяет результат и сразу выдаёт выигрыш в инвентарь (при переполнении — бросает у игрока). Клиент рисует 4-секундное вращение, замедление и остановку на зелёном/красном секторе. Это визуализация исхода, не клиентская жеребьёвка. Чтобы не хранить неподтверждённые награды, выдача происходит ДО окончания анимации. В инвентаре выигрыш поэтому может быть заметен раньше.

Закрытие GUI не отменяет результат. Неиспользованный вход возвращается. Внутри открытого меню действует блокировка повторной попытки/смены цели на 80 тиков. Закрытие и повторное открытие позволяет начать новую отдельную платную попытку без ожидания, но не переиграть старую.

Содержимое контейнеров и мешков не принимается. Остальные компоненты входа (имя, зачарования, повреждение и т.п.) не оцениваются отдельно и уничтожаются вместе с израсходованным предметом. Выход — новый обычный ItemStack без дополнительных пользовательских компонентов.

## Цены и аддоны
На старте сервера заполняется config/create-upgrader-prices.json всеми фактически зарегистрированными предметами. Поэтому Create и его установленные аддоны обнаруживаются без угадывания mod ID. Все немайнкрафтовые предметы получают повышенные эвристические цены (включая другие моды).
Яйцо дракона всегда 20000. Остальные цены максимум 19999. 0 — запрещено. /upgrader reload доступна оператору и обновляет прайс. Изменения сохраняются, новые ID добавляются при загрузке.
Прежний файл цен совместим. При его сохранении не изменятся уже записанные стартовые цены.

Цены НЕ вычисляются по рецептам. Гарантии «любой предмет дороже автоматического производства» нет. Для реального баланса и защиты от арбитража требуется аудит конкретных рецептов сборки. Часть служебных предметов запрещается эвристически; перед публичным сервером просмотреть JSON и вручную запретить остальные опасные/технические предметы.

## Проверки перед игрой
1. Выполнить сборку и проверить отсутствие ошибок.
2. Запустить чистый тестовый клиент и dedicated server с точными версиями модов.
3. Проверить /give, ПКМ, переносы Shift-click, поиск, страницы, выбор и синхронизацию цен.
4. Проверить dirt=1 и oak_log=4: шанс 20%.
5. Проверить успех/неудачу, закрытие во время анимации, переполнение инвентаря, смерть/выход, запрет контейнеров.
6. Проверить прайс всех предметов Create и аддонов до использования в основном мире.

В проекте нет сторонних библиотек GUI, отдельного блока, энергии, воронок и интеграции JEI. Выбор цели передаётся серверной командой /upgrader select namespace:item, доступной только когда открыто меню; запуск — стандартной кнопкой контейнера. Все цены/расходы/выдачи проверяются на сервере.
